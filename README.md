This repository demonstrates a Flask-Based Web App that you can use to evaluate your data against a set of classifiers.

Reproduction is easy:
1. Clone this repository
2. Run command: pip install -r requirements.txt
3. Run: python app.py

Currently there is support for four algorithms:
1. Bayes Classifier
2. k-Nearest Neighbor
3. Ho-Kashyap Algorithm
4. Parzen Window Technique
